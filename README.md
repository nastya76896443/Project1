The program generates random cells on a square board of size `n × n` and determines the size of the free zone — the number of cells that are neither selected nor adjacent to the selected cells. The experiment is repeated a specified number of times, after which the mean and median values of the free-zone size are calculated. The program also studies how the size of the free zone depends on the ratio `m/n²`. The input data are read from `input.txt`, and the results are written to `output.txt`.
